# variables.md

This file documents all the variables (including environment) that is used as config in the script.

# Config Variables:

> **NOTE:** No config variables are present

# Environment Variables:

## Required Environment Variables
- `TOKEN`: Discord application token
- `MC_SERVER_MANAGER_URL`: Endpoint to an MCServerManager instance. Only the base URL

## Optional Environment Variables
- `GUILD_ID`: Responds to a specific server if provided
- `WOL_URL`: Endpoint to an SARAB Home WOL instance. Used for `/wol` command.
