# discord_commands.md

This file contains all the commands supported by this application. Prefix is **'/'**.

- `hello`: Say hello!
- `echo`: I will echo anything you give me to echo
- `mcserver_start`: Start an existing Minecraft server
- `mcserver_stop`: Stop an existing Minecraft server
- `mcserver_backup`: Backup an existing Minecraft server
- `mcserver_command`: Send command to an existing Minecraft server
- `wol`: Send wake-on-lan magic packet to a device
